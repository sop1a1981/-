# 네이버 스마트플레이스 등록·운영 절차

아로마스 청라 기준. 기준일 2026-08-27.

지역 업체에게는 이게 블로그보다 먼저다. `청라 마사지`를 검색하면
**플레이스 목록이 블로그 글보다 위에 뜬다.** 블로그 SEO를 아무리 해도
플레이스가 비어 있으면 그 위 자리를 통째로 비워두는 셈이다.

---

## 0단계 — 이미 등록돼 있는지부터 확인

네이버 지도에서 **"아로마스 청라"**를 검색한다. 결과가 셋 중 하나다.

| 상태 | 할 일 |
|---|---|
| 업체가 안 뜬다 | 아래 1단계부터 신규 등록 |
| 뜨는데 내 계정에 없다 | 신규 등록 ❌ → **업체 정보 수정 요청 / 권한 요청**으로 소유권을 가져온다 |
| 뜨고 내 계정에도 있다 | 등록은 끝. 3단계 운영 항목만 점검 |

**중복 등록은 절대 하지 않는다.** 같은 업체가 두 개 뜨면 리뷰·평점이
쪼개지고, 네이버가 어느 쪽을 노출할지 흔들린다. 합치는 게 새로 만드는
것보다 훨씬 번거롭다.

> 지도에 이미 올라가 있는 경우가 흔하다. 손님이 등록했거나, 예전에
> 만들어두고 잊었거나, 배달·예약 플랫폼이 자동 생성한 경우가 있다.

---

## 1단계 — 준비물

등록 화면에 들어가기 전에 미리 갖춰 둔다. 중간에 끊기면 처음부터 다시다.

- [ ] **사업자등록증** — PDF 또는 이미지 파일
- [ ] **네이버 계정** — 사업자등록증과 **같은 명의**여야 한다.
      앞으로 계속 관리할 계정으로 로그인한다 (직원 개인 계정 ❌)
- [ ] **업종에 맞는 추가 서류** — 업종을 고르면 등록 화면이 무엇이
      더 필요한지 알려준다. 마사지·테라피 업종은 사업자등록증 종목에
      따라 추가 서류를 요구받을 수 있으니 화면 안내를 그대로 따른다
- [ ] **사진** — 최소 10장 이상 권장
      - 외관 (건물 입구, 간판) ← **가장 중요**. 처음 오는 손님이 못 찾으면 이탈한다
      - 내부 (대기 공간, 시술실)
      - 시술 도구·오일 클로즈업
      - ⚠️ 인물 사진은 초상권 동의를 받은 것만
- [ ] **시술 메뉴와 가격** — 코스명·시간·가격
- [ ] **영업시간** — 실제와 다르면 리뷰에서 바로 지적당한다

---

## 2단계 — 등록

1. **smartplace.naver.com** 접속 → 준비한 네이버 계정으로 로그인
2. **[업체 신규 등록]** 클릭
3. **업종 선택** — 사업자등록증에 적힌 **종목**을 검색해서 고른다.
   종목명으로 안 찾아지면 업체를 대표하는 키워드로 검색한다
4. **업체 정보 입력** — 상호, 주소, 전화번호, 영업시간
5. **서류 첨부** — 사업자등록증 + 화면이 요구하는 추가 서류
6. **제출 후 심사 대기**

**심사 기간: 영업일 기준 최소 2시간 ~ 최대 5일.**
프로모션이나 오픈 일정이 있으면 최소 일주일 전에 시작한다.

---

## 3단계 — 등록 후 (여기가 실제 노출을 만든다)

등록만 하고 비워두는 업체가 대부분이다. 아래를 채우는 것만으로 경쟁 업체를 앞선다.

### 업체명

- [ ] **실제 상호 그대로.** `청라마사지아로마스` 같은 키워드 끼워넣기는
      네이버 제재 대상이다. 적발되면 노출이 내려간다 — 얻는 것보다 잃는 게 크다
- [ ] 지점이 있으면 `아로마스 청라본점`처럼 정식 지점명까지만

### 대표 키워드 / 상세 설명

- [ ] 대표 키워드에 **사람들이 실제로 치는 말**을 넣는다:
      `아로마마사지`, `전신마사지`, `림프마사지`, `타이마사지` 등
- [ ] `패시브스트레칭테라피`는 브랜드 용어라 검색량이 거의 없다.
      상세 설명에서 설명하되, 대표 키워드는 일반 검색어로 잡는다
- [ ] 상세 설명에 증상 키워드를 자연스럽게:
      어깨 통증, 목 뭉침, 만성 피로, 부종 — 블로그 주제와 일치시킨다

### 메뉴·가격

- [ ] 코스별 시간·가격을 전부 등록한다. **가격이 없으면 문의 전에 이탈한다**
- [ ] 첫 방문 할인 등이 있으면 여기에

### 블로그 연결 ← 가장 큰 시너지

- [ ] 스마트플레이스에 **블로그를 연동**한다. 블로그 글이 플레이스
      상세 화면에 함께 노출된다
- [ ] 지금 진행 중인 제목 수정·신규 12편이 여기로 흘러들어온다.
      플레이스에서 블로그로, 블로그에서 예약으로 이어지는 동선이 완성된다

### 예약·문의

- [ ] 네이버 예약 또는 톡톡 연결 — 전화만 열어두면 통화가 부담스러운
      2030 고객을 놓친다
- [ ] 24시간 운영이면 그 점을 상세 설명 앞쪽에 명시. 경쟁 업체 대비
      명확한 차별점이다

### 리뷰

- [ ] 방문자 리뷰를 꾸준히 쌓는다. 시술 후 자연스럽게 요청하는 정도까지만
- [ ] 리뷰에 **답글을 단다.** 답글 있는 업체가 없는 업체보다 신뢰를 얻는다
- [ ] ❌ **대가를 주고 리뷰를 받지 않는다.** 네이버 제재에 더해
      공정거래위원회 표시광고법 위반이다. 실제 과징금 사례가 있다

---

## 하지 말 것

- ❌ 업체명·설명에 키워드 도배
- ❌ 중복 업체 등록
- ❌ 대가성 리뷰, 리뷰 품앗이
- ❌ 실제와 다른 영업시간·주소
- ❌ 순위를 올려주겠다는 대행업체 — 네이버가 잡아내면 업체가 책임진다

---

## 확인하지 못한 것

- **아로마스가 이미 플레이스에 등록돼 있는지** 확인하지 못했다.
  네이버 지도는 외부 검색으로 조회가 잘 되지 않는다. 0단계를 직접 해봐야 한다.
- **마사지·테라피 업종의 정확한 추가 서류** — 업종과 사업자등록증
  종목에 따라 달라지고, 등록 화면에서 그때그때 안내된다. 미리 단정하지 않는다.
