**할 일:** 스마트플레이스 관리 → 대표 링크를 블로그

## 🟠 2순위 — 메뉴 상단 문구의 광고법 리스크

메뉴 첫 줄이 이렇게 들어가 있다.

```
🥇청라마사지 고객만족도No.1🥇
```

**"No.1" 표방은 객관적 실증 자료가 없으면 표시광고법 위반이다.**
조사 주체·비교 대상·조사 시점이 명시되지 않은 1위 표현은 부당광고로
제재받는다. 리뷰 489개에 4.93점이라는 진짜 실적이 있는데
굳이 법적 위험을 지는 문구를 쓸 이유가 없다.

**대안 — 사실만으로 더 강하다:**

```
방문자 리뷰 489개 · 평점 4.93 (2026.08 기준)
```

숫자가 근거를 스스로 갖고 있어서 실증 문제가 생기지 않고,
"No.1"보다 구체적이라 설득력도 높다.

## 🟡 3순위 — 업종 카테고리 확인

현재 업종이 **"피부,체형관리"**로 등록되어 있다. `청라 마사지`로
검색했을 때 마사지 업종 필터에서 빠질 가능성이 있다.

다만 **이건 의도적일 수 있다.** 마사지업은 안마사 자격 관련 규제가
있어 "피부·체형관리"로 등록하는 것이 오히려 정확한 경우가 많다.
사업자등록증 종목과 실제 운영에 맞는 분류라면 **그대로 두는 게 맞다.**

**확인만 해달라:** 사업자등록증 종목과 현재 업종이 일치하는가.
일치한다면 손대지 않는다. 업종을 실제와 다르게 바꾸는 건 더 큰 위험이다.
