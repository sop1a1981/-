# 아로마스 네이버 블로그 팀에이전트

인천 청라 마사지샵 **아로마스**의 네이버 블로그 콘텐츠를 자동 생성하는
멀티에이전트 시스템입니다.

발행처: `blog.naver.com/aromas-cheongna`

## 파이프라인 (Step 0~7 순차 실행)

```
[Step 0] PM 총괄 기획자    포스팅 브리프 (방향·타깃·주의사항)
  ↓
[Step 1] SEO 전략가        키워드 설계 + 제목 후보 3개
  ↓
[Step 2] 콘텐츠 라이터     블로그 본문 1,500~2,500자
  ↓
[Step 3] 텍스트마이닝      키워드 밀도 분석 + 보완
  ↓
[Step 4] QC 검수관         9개 항목 검수 + AI 작성 지수 수치화
  ↓
[Step 5] PM CTA 확인       전환형(BOFU)만 — 그 외에는 건너뜀
  ↓
[Step 6] 카드뉴스 기획자   7~10장 구조 설계
  ↓
[Step 7] 디자이너          카드뉴스 디자인 설계서
  ↓
최종 산출물: 블로그 본문 1편 + 카드뉴스 세트 1개
```

각 에이전트의 시스템 프롬프트는 `agents/step_XX_*.md`에 있습니다.
**동작을 바꾸려면 이 .md 파일을 고칩니다.**

## 설치

```bash
pip install -r requirements.txt
```

`claude-agent-sdk`를 쓰므로 **API 키가 필요 없습니다.** Claude Pro 구독으로
실행됩니다.

## 사용법

```bash
# 계획만 출력 (호출 없음) — 먼저 이걸로 확인
python main.py --dry-run

# 특정 포스팅만 생성 (1-12)
python main.py --post-id 3

# 전체 12개 생성
python main.py

# 전환형(BOFU) 건너뜀 — CTA 미승인 시
python main.py --skip-bofu
```

⚠️ **실행 전 `git status`로 워킹 트리를 비워두세요.** 커밋되지 않은 변경이
있으면 stop hook이 에이전트 호출마다 발동해 결과에 git 메시지가 섞여
들어갑니다.

## 발행 계획

기존 블로그 50편의 주제 커버리지를 분석해, **아직 다루지 않은 검색 수요만**
골라 4주 × 3편으로 구성했습니다. 계획은 `config.py`의 `WEEKLY_POST_PLAN`에
있고 `--dry-run`으로 확인할 수 있습니다.

| 주차 | 축 | 편수 |
|---|---|---|
| 1주차 | 결정 단계(BOFU) 공백 메우기 | 3 |
| 2주차 | 병명 검색어 (오십견·수족냉증 등) | 3 |
| 3주차 | 여성 타깃 신설 (생리통·산후) | 3 |
| 4주차 | 시즌(추석) + 지역 전환 | 3 |

각 항목의 `target_keyword`는 Step 0·1로 전달돼 **메인 키워드로 고정**됩니다.
에이전트가 매번 키워드를 새로 지어내면 계획과 실측 순위를 대조할 수 없기
때문입니다.

## 운영 주의사항

- **CTA는 BOFU만.** 정보성 글에 예약 유도를 넣으면 신뢰가 깎입니다.
  Step 4 QC가 걷어내고, Step 5에서 PM이 따로 확인합니다
- **의료법** — "치료됩니다" → "불편감이 나아졌다는 분들이 많아요".
  "완치", "의학적으로 증명" 등 직접적 효능 주장 금지
- **표시광고법** — "1위", "최고", "No.1"은 객관적 실증 자료 없이 쓰면
  위법입니다. 실적은 사실로만 (리뷰 수·평점)
- **자기잠식 주의** — 기존 50편이 이미 덮은 주제로 새 글을 쓰면 자기 글끼리
  경쟁해 둘 다 순위가 내려갑니다
- **발행 후 잦은 수정 금지** — 네이버는 수정·삭제 반복을 문서 신뢰 점수에서
  깎습니다. 고칠 것은 모아서 한 번에
