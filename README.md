# 아로마스 스레드 팀에이전트

인천 청라 마사지샵 **아로마스**의 스레드(Threads) SNS 콘텐츠를 자동 생성하는 멀티에이전트 시스템입니다.

## 에이전트 구성

```
[PM] 운영자가 주제 방향 결정
  ↓
[SEO 전략가]   키워드 설계 + 제목 후보 3개
  ↓
[콘텐츠 라이터] 본문 초안 작성
  ↓
[텍스트마이닝]  키워드 밀도 분석 + 보완
  ↓
[QC 검수관]    체크리스트 검수 + AI 작성 지수 수치화
  ↓
[PM] CTA 포함 여부 최종 승인 (전환형만)
  ↓
[카드뉴스 기획자] 7-10장 구조 설계
  ↓
[디자이너]      카드뉴스 디자인 설계서 작성
  ↓
최종 산출물: 스레드 포스팅 1개 + 카드뉴스 세트 1개
```

한 번 실행 시 **7일치 10개 포스팅**을 일괄 생성합니다.

## 설치

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="your-api-key"
```

## 사용법

```bash
# 전체 10개 포스팅 생성
python main.py

# 특정 포스팅만 생성 (1-10)
python main.py --post-id 3

# 계획만 출력 (API 호출 없음)
python main.py --dry-run

# 전환형(BOFU) 건너뜀 — CTA 미승인 시
python main.py --skip-bofu
```

## 주간 포스팅 구성 (10개)

| # | 유형 | 퍼널 | 주제 |
|---|------|------|------|
| 1 | 문제 공감형 | TOFU | 어깨·목 통증 |
| 2 | 문제 공감형 | TOFU | 만성 피로 |
| 3 | 문제 공감형 | TOFU | 몸이 무거운 이유 |
| 4 | 정보·지식형 | MOFU | 병원 이상 없는데 왜 아픈가 |
| 5 | 정보·지식형 | MOFU | 혈액순환과 통증의 관계 |
| 6 | 케이스·경험형 | MOFU | 만성 목 통증 3회 변화 |
| 7 | 케이스·경험형 | MOFU | 어깨 결림 직장인 사례 |
| 8 | 시리즈 연재 | TOFU | 통증 없는 일상 7일 프로젝트 1편 |
| 9 | 시리즈 연재 | MOFU | 통증 없는 일상 7일 프로젝트 2편 |
| 10 | 전환형 | BOFU | 전자책·예약 CTA (PM 승인 필요) |

## 산출물

`output/` 디렉토리에 포스팅당 2개 파일 생성:
- `post_01_*.json` — 전체 데이터 (SEO, 본문, QC, 카드뉴스, 설계서)
- `post_01_*.txt` — 사람이 읽기 편한 텍스트 형식

## 운영 주의사항

- **CTA는 PM 승인 필수** — 전환형(#10) 포스팅은 반드시 PM이 확인 후 발행
- 의료적 효능 직접 주장 금지 ("치료됩니다" → "불편감이 나아졌다는 분들이 많아요")
- 인스타그램 연동 상태 유지 필수
- 통증·마사지·힐링 니치 카테고리를 벗어나지 않을 것
